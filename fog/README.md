# Fog contract subtree

This subtree is the provisional canonical home for FogStack control-plane contracts within `SocioProphet/api-spec`.

Current contents:
- OpenAPI specs for topology and planner APIs
- AsyncAPI spec for telemetry and alerts bus
- JSON Schemas for identity, posture, deployment profile, and claim
- CUE profile bundle seed
- ADRs for substrate positioning and identity as prime plane
- example deployment profile documents

Follow-up work should extend this subtree before creating new runtime repos.
